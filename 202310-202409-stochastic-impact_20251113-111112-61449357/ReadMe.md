\# Read Me



This folder contains an orderly packit that collates individual model/ disease estimates of stochastic impact ratios into one output. The output file 'all\_impact\_ratios' is larger than the allowed file limit of GitHub; however, the processed impact ratios can be examined in 'paper-four-figures...' and is named 'stochastic\_impact\_ratios.rds'. In this folder, each 'dat...rds' corresponds to one modelling group. Sensitive estimates for malaria and COVID are available on request and subregional estimates for malaria are available to download from our data visualisation tool 'VAXVIZ'.
